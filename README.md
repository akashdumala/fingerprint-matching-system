# Fingerprint Matching System

A biometric fingerprint matching system developed using Python and OpenCV.

## Features

- Image Loading
- Fingerprint Preprocessing
- Normalization
- Enhancement
- Gabor Feature Extraction
- Euclidean Distance Matching
- Genuine vs Imposter Evaluation
- ROC Curve Generation
- Matching Score Export
- Automatic Report Generation

## Technologies

- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-Learn

## Dataset

FVC2002 DB1
